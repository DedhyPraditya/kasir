# NYEMIL BEBS - Mobile POS (Flutter)

Aplikasi kasir mobile Android berbasis Flutter untuk usaha kuliner Nyemil Bebs.

## 🚀 Fitur Utama

- **Icon Resmi Nyemil Bebs**: Memakai logo resmi toko Nyemil Bebs dengan Android adaptive icons.
- **Kasir & Keranjang Belanja**: Pemilihan varian rasa, topping, perhitungan harga dan kembalian otomatis.
- **Cetak Printer Thermal Bluetooth**: Terhubung langsung ke printer thermal 58mm via Bluetooth.
- **Preview Thermal 100% Presisi**: Simulator tampilan struk baris-per-baris identik hasil cetak fisik.
- **Halaman Riwayat Transaksi Hari Ini**: Fitur cetak ulang struk & share struk gambar (JPG/PNG).
- **In-App Auto Update**: Pengecekan dan unduhan otomatis jika ada versi baru di server VPS.
- **Indikator Printer & Bottom Navigation**: Navigasi bawah modern (Home, Riwayat, Setting) dan indikator koneksi printer (🟢/🟠).
